02 业务产品层下一阶段主战场 ▾
两条核心产品线 待制作
  • EGO 专业采集 — 高精度复杂任务;第一视角、多传感器同步、深度与位姿数据 → 三折页 + 单页
  • iPhone 众包采集 — 规模化长尾场景;低成本、分散人员、真实场景 → 三折页 + 单页
  • 先做母版 — 定一套"业务页母版"(封面逻辑、图位、数据位、联系位),两条产品线套用,保证系列感
  • 每页结构 — ①解决什么问题 ②怎么做到(技术亮点) ③参数/规格表 ④典型场景 ⑤案例或数据背书 ⑥联系方式+二维码
  • 双版本输出 — 电子版(PDF/长图,线上发)与印刷版(出血尺寸,展会发)分开出
数采业务资产(官网已有,可复用)
  • 数据背书 — 800+ 场景 / 30 万+ 小时 / 2PB 存储 / 50+ SOP
  • 场景覆盖 — 家庭、仓储、零售、工业
  • 生产流程 — 任务定义 → 多产品采集 → 数据处理 → 质量闭环 → 训练资产
  • 这些数字与流程可直接搬到三折页,形成"官网—折页"一致口径。
03 视频内容层新增重点 ▾
产品使用视频 Q4 制作
视频类型清单
  • 产品演示片 — EGO / iPhone 采集实拍,展示第一视角任务记录(如叠被)
  • 公司介绍片 — 1.5–3 分钟,官网首屏 + 展会展台循环播放
  • 操作教程片 — 采集 SOP 分步演示,用于内部培训与客户上手
  • IP 动画短片 — IP 形象动起来,用于社交传播与展会吸引人流
  • 案例短视频 — 标杆项目 30–60 秒,公众号/视频号投放
制作流程与规范
  • 脚本先行 — 每个视频先出脚本 + 分镜,确认后开机
  • 统一片头片尾 — 片头 LOGO 动版、片尾联系方式 + 二维码,形成系列识别
  • 统一字幕与配色 — 字幕字体、角标、转场按 VI 执行
  • 素材归档 — 原始素材按"日期_项目_场景"命名存档,便于二次剪辑
投放位
  • 官网首屏 / 产品详情页内嵌
  • 视频号 + 公众号(配合图文推送)
  • 展会大屏循环 / 销售拜访时平板即放
  • 电子物料库打包,销售随手可发

05 渠道投放层物料做好后往哪投 ▾
线上渠道
  • 官网 — 产品页/案例页/留资表单,品宣第一落点
  • 公众号 + 视频号 — 图文 + 视频双线输出
  • 行业媒体 / 垂直平台 — 机器人、AI、具身智能类媒体供稿
  • 电子物料库 — 所有折页/视频一键发送,方便销售转发
线下渠道
  • 行业展会 — 展台 + 折页 + 视频循环 + IP 立牌组合拳
  • 客户拜访 — 销售随手包:公司页 + 对应业务页 + 视频 + 名片
  • 行业活动 / 论坛 — 演讲 PPT 统一 VI,借势传播
对内渠道 易漏
  • 全员物料库 — 让每个同事都拿得到、用得对
  • 销售赋能话术 — 物料配话术,不只是给图
  • 内部统一口径 — 公司定位、产品说法一致,避免对外口径混乱
06 对内协同机制品宣服务市场的保障 ▾
需求流转流程
  • 业务方提需求 → 品宣排期 → 出稿 → 评审 → 定稿归档
  • 设 物料申请单(部门/用途/交期/尺寸),避免口头插单
  • 明确 响应时效:标准物料 X 天,新物料 X 天
品宣职能定位
  • 品宣是服务市场与业务的支撑部门,不是单纯做设计的
  • 主动对接业务:先懂产品,再谈物料
  • 建立 物料台账:版本、更新日期、责任人
评审与迭代
  • 物料上线后收集销售/客户反馈,季度迭代一次
  • 重要物料做 A/B:不同版本看客户反馈
07 内容与场景层从产品讲到价值 ▾
按行业场景包装 待补
  • 场景化方案页 — 不卖产品卖场景:家庭场景采集、仓储/零售采集、工业采集
  • 客户案例集 — 标杆项目做成 1 页/项目的案例卡,最有说服力
  • 行业解决方案白皮书 — 长内容,用于高价值客户与行业展会
内容形式矩阵
  • 图文 — 单页 / 三折页 / 海报 / 展板
  • 视频 — 产品演示 / 公司介绍 / IP 动画 / 案例短片
  • 数字 — 官网、公众号、视频号、电子画册(H5)
  • 实物 — 易拉宝、展台、工服、礼品/IP 周边
08 帮你补齐的关键项别漏了这几点 ▾
容易遗漏但很重要 重点
  • 品牌手册 — 没有它,业务页做十版就会走样十版
  • 业务页母版 — 比单个产品页更重要,决定系列感与效率
  • 视频片头/片尾统一 — 视频是系列内容,识别度靠统一包装
  • 案例卡 — B 端最有效的品宣内容,建议尽早启动
  • 电子物料库 — 品宣"服务市场"的核心抓手,让销售随时能用
  • 物料台账与版本管理 — 防止新旧版本混用造成对外口径混乱
  • 官网与物料口径一致 — 数据(800+ 场景/30 万+ 小时)全渠道统一
  • IP 应用边界 — IP 活泼、B 端要专业,需明确使用场合
