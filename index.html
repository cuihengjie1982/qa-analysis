03 / 口径与行动

怎么读这份结果？

组织维度只拿到了不通过明细，因此本页不把不通过条数误读成组织不通过率。

DCE · 数据内容错误

双手协调、生产价值、任务意图、重复动作、画面视角 / 亮度 / 稳定性等，优先通过采集员动作、机位和试拍训练修正。

PCE · 流程 / 项目错误

任务类型与时长、场景 / 环境 / 标题打标、未填写原因等，优先通过任务卡、打标培训和 QC 记录流程修正。

CCE · 合规 / 安全红线

他人身体部位、敏感信息、碰水等风险，必须先隔离，不按普通质量问题容错；录前清场和抽检要前置。

统计口径：组织归并键 = 上级用户 ID；同一 ID 下不同昵称合并展示；不通过记录 = 明细行数；问题项 = “不通过原因”按分号拆分后的次数。分析窗口 = 近三期质检（2026/08/21、08/23、08/24，8/22 仅 12 条不计入）；早期质检日（8/17–8/20）因团队尚未掌握质检要求，不纳入分析。因源报表仅提供全区间质检总量与通过率，窗口内无法重算通过率，故本页只展示由明细可准确重算的指标。源文件：质检报表_当前条件_20260812_20260830.csv。
组织质检不通过分析 · 近三期（2026/08/21、08/23、08/24）建议先做 CCE 隔离，再按组织 TOP3 问题定向整改。
